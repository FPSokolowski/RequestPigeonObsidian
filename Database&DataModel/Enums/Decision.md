At next phase add DelayedAccept - possibility to accept request but "not now"/"not yet". Example: an employee requested for a new computer in December. An acceptance realize this spend is necessary/valid but isn't urgent. Budget for current year doesn't allow for any more spends. So manager decide to accept a request but with delayed consequences(till January) - so the employee will be able to buy the new device next month from a new budget.
